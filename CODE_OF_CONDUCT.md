# Contributor Covenant Code of Conduct (v2.1, abridged)

We pledge to make participation harassment-free for everyone, regardless of age, disability, ethnicity, gender, experience, nationality, race, religion, or sexual identity.

## Expected

- Use welcoming language. Respect differing viewpoints. Accept constructive criticism. Focus on community benefit.

## Unacceptable

- Sexualized language/imagery, trolling, insults, personal attacks, harassment (public or private), publishing private info without consent.
